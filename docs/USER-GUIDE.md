# Yy Sustainer 用户手册

> 面向使用安装包的非开发者用户。开发与源码相关内容见 [README](../README.md)。

## 它是什么

一个完全运行在你自己电脑上的 AI 助理：能对话、执行任务（读写文件、跑命令、上网查资料）、
定时干活（每天早上生成简报之类）、长期记住你的偏好。所有数据都在你自己电脑的
`C:\Users\<你>\.yyagent\` 目录里，没有任何云端依赖。

## 安装与首次启动

1. 从 [Releases](https://github.com/YYMY034/Yy-Sustainer/releases/latest) 下载
   `Yy Sustainer-x.y.z-Setup.exe`，双击安装
2. 首次启动若弹 SmartScreen（本版本未做代码签名）：点「更多信息」→「仍要运行」
3. 首次会引导你二选一：内置本地模型（自动下载、免 Key、离线可用）或填自己的 API Key

## 日常使用

- **发任务**：输入框直接说人话（「把桌面这周新增的文件列个清单」「帮我查 XX 然后写个摘要」），
  Enter 发送，Shift+Enter 换行
- **停止 / 撤回**：任务跑偏了点「停止」；发错消息可撤回编辑
- **附件**：直接把图片拖进输入框；表格/文档类任务它会自己调对应的工具
- **后台任务**：长命令会自动转后台，「自动化」页能看到后台任务列表和日志
- **过程可见**：输出区的状态行显示「第 N/M 步 · 已等 Ns · 本回合 token 数」，
  并行子任务各有各的进度行

## 自动化（定时任务）

「自动化」页 → 新建定时任务：名字 + cron 计划 + 要它做什么。到点无人值守执行，
完成/失败弹系统通知。常用计划：`0 9 * * *`（每天 9 点）、`0 9 * * 1-5`（工作日 9 点）。

## 设置页要点

- **模型**：主对话模型与识图模型分开选；换 Key 后点测试；模型行悬停可为每个模型单独设推理档位（低/中/高）
- **权限**：三档——全部确认 / 危险操作确认（默认，推荐）/ 完全允许
- **外观**：深色/浅色一键切换；五套主题色（石墨=默认白底黑字中性风、翠绿、蔚蓝、紫罗兰、暖橙），选择即时生效并记住
- **数据与安全**：自动备份（滚动 zip）、**诊断导出**（报障时下载附给 issue）、会话归档天数
- **局域网访问**：默认只监听本机；要在手机上用需开启共享并配对（设置页查看配对码）

## 数据都在哪

`C:\Users\<你>\.yyagent\`：`sessions/`（对话记录）、`memory/`（长期记忆）、
`backups/`（自动备份）、`config.json`（配置，API Key 已加密）。整个目录拷走 = 整机迁移。

## 常见问题

- **报错「需要配对 token」**：你在用别的设备访问。在本机打开应用 → 设置页看配对码，输入即可
- **任务没跑**：「自动化」页看是否停用；任务超时默认 10 分钟，长任务在提示词里让它分步
- **想换电脑**：停掉应用，整个 `.yyagent` 目录拷过去
- **遇到 bug**：设置页导出诊断 JSON，到 [Issues](https://github.com/YYMY034/Yy-Sustainer/issues) 提交
