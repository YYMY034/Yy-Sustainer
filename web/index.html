添加模型

如何获取接入信息？
1. 打开你的模型服务商控制台（如智谱、阿里百炼、OpenRouter、硅基流动、Ollama 等），找到 API Keys 页面创建一个密钥；
2. 复制该服务商的 API Base URL（OpenAI 兼容接口地址，一般以 /v1 结尾，如 https://open.bigmodel.cn/api/paas/v4）；
3. 在服务商的模型列表里复制要用的模型 ID（如 glm-4.7、qwen-max、deepseek-chat）；
4. 填到下方即可。本地模型（Ollama / LM Studio）Base URL 填 http://127.0.0.1:11434/v1，API Key 随便填一个即可。
常见：智谱 https://open.bigmodel.cn/api/paas/v4 · 硅基流动 https://api.siliconflow.cn/v1 · OpenRouter https://openrouter.ai/api/v1
